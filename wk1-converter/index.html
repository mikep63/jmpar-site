WK1 Converter

Open old Lotus 1-2-3 spreadsheets on a Mac, look through them, and save them as CSV or Excel.

Support

For questions or problems, email support@jmpar.com. If a file doesn't open or converts wrongly, please say which program wrote it (Lotus 1-2-3 and its release, if you know) and what you expected to see. Only attach the file if you're happy to share what's in it.

What it does

  • Opens Lotus 1-2-3 .WK1 files: double-click one in Finder, use File ▸ Open, or drop it on the Dock icon. The sheet shows in a grid, and nothing is written until you export it.
  • Exports as CSV (⌘E) or as an Excel workbook (⇧⌘E).
  • File ▸ Convert Files converts a whole batch: drop in files or folders, choose CSV or Excel, and save next to each original or into one folder.
  • Select rows and press ⌘C to copy them, ready to paste into Excel or Numbers.
  • Includes wk1-converter, a command-line tool for scripts.

What it reads

Numbers, text, and for a formula cell the result Lotus last stored. Text is read the way DOS Lotus stored it (code page 437), so accented letters come through.

View ▸ Show Formulas (experimental) shows the formulas themselves where every part of them can be read, and exporting with it on writes them as real Excel formulas. A list of every formula, and why any was left as a value, is saved next to the export. It was checked on real Lotus files: of 1,418 formulas, 1,340 convert, and each recalculates to the result Lotus stored.

What it does not keep

Number formats, dates (they come through as Lotus date numbers), column widths, and charts. It reads .WK1 files only, not the older .WKS or the newer .WK3 and .WK4 formats.

Requirements

macOS 13 Ventura or later, on Apple silicon or Intel Macs.

Windows version

For Windows, wk1-converter reads the same files and writes the same CSV and Excel output.
